# Rasika Wale — Portfolio

A personal portfolio website built with React and Vite.

## Technologies Used

- React
- Vite
- JavaScript
- CSS
- ESLint / Oxlint

## Getting Started

Clone the repository and install the dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Build the project for production:

```bash
npm run build
```

Preview the production build:

```bash
npm run preview
```

## Features

- Responsive portfolio homepage
- Personal introduction and project showcase
- Skills and resume information
